# Security policy

Browsekit runs on every page you visit, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: on this repository, open the **Security** tab and choose **Report a vulnerability**.

Include the feature involved, the browser and Browsekit version, and the steps or a page that reproduces it. You should get a reply within a week.

## Supported versions

Only the latest release receives fixes.
